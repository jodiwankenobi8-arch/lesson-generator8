# Lesson Generator 8 Extra Orchard Elements Asset Pack

Transparent PNG cutouts extracted from the uploaded orchard/stationery element sheets.

## Intended visual direction

Use these as realistic image/material assets and tactile stationery elements:
- paper labels and torn paper strips
- apple orchard accents
- stitched fabric ribbons and gingham pieces
- teacher-planner scrapbook vignettes
- small woodland/mushroom accents used sparingly

## App-use rules

- Keep all app text, buttons, form fields, headings, and controls as real accessible HTML.
- Use these files only as decorative/material image layers.
- Add one visual seam at a time and run `npm run verify:release` after each code/styling pass.
- Do not replace app screens with screenshots.
- Do not wire the whole pack into the UI at once.
- Do not let the mushroom set overwhelm the apple-orchard/teacher-planner identity.

## Suggested next seams

1. Add one shared section-label component that uses a single stitched ribbon/label asset behind real HTML text.
2. Add one small non-interactive orchard accent to the page header or empty-state area.
3. Add one content-panel paper label layer for material traceability or exemplar payoff sections.

The uploaded source sheets had baked checkerboard backgrounds. The production files in this pack are transparent PNG cutouts.
