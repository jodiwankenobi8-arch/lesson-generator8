# Asset 01: wood-background-orchard

Professional asset package for a warm horizontal wooden plank background used in the Apple Orchard design system.

## Included files

- `wood-background-orchard.png` — high-definition raster asset
- `wood-background-orchard.svg` — scalable vector approximation for UI and prototyping use
- `wood-background-orchard.css` — reusable CSS class and custom properties
- `WoodBackgroundOrchard.tsx` — React component for app/web integration
- `wood-background-orchard.tokens.json` — design tokens and metadata
- `index.ts` — barrel export for codebases

## Usage guidance

Use this asset as a base layer behind cards, scrapbook panels, parchment forms, and decorative orchard UI elements. Prefer the React/CSS versions for product implementation. Use the PNG for mockups or exact art placement.

## Notes

- The PNG is the highest-fidelity visual asset in this package.
- The SVG and CSS versions are implementation-friendly approximations of the same visual language.
- The React component is designed to be dropped into a modern TypeScript + Tailwind or CSS-module project.
