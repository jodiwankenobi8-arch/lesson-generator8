# Lesson Generator 8 Ribbon Label Asset Pack

This pack contains transparent PNG cutouts extracted from the uploaded stitched ribbon/label sheet.

## Intended use

Use these as realistic image/material assets and tactile stationery elements in the app, while keeping all headings, labels, buttons, form controls, and teacher-facing text as real accessible HTML.

Recommended visual seams:
- page/header label image layer
- section/ribbon label image layer
- small decorative corner accent
- non-interactive material layer behind real text

## Do not

- Do not replace app screens with screenshots.
- Do not convert controls into static image buttons.
- Do not wire all assets at once.
- Do not use the source reference sheet directly as a UI layer; it has a baked checkerboard backdrop.
